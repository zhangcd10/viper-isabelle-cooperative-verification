# Bridging Automatic and Interactive Verification: BFS Case Study

## Files

- `BFS_viper.vpr`  
  Verification of BFS reachability in Viper.

- `BFS_Isabelle.thy`  
  Independent verification of BFS reachability in Isabelle/HOL.

- `BFS_program obligation.rtf`  
  Program obligation generated by the Silicon symbolic execution backend of Viper. The program obligation generated by Silicon is used as a bridge between the two systems.

- `BFSDebug.thy`  
  Isabelle/HOL lemma used to solve the remaining verification difficulty from the program obligation.

The case study shows how interactive verification can help explain and improve difficult automatic verification problems.
